# Test Plan: RestFul_Booker

## 1. Introduction

*   This document outlines the test strategy for the RestFul_Booker project, focusing on delivering a high-quality application through a phased approach incorporating Shift Left Testing and Exploratory Techniques.

## 2. Test Objectives

*   Verify that all requirements are fully explored and understood by the testing team.
*   Ensure the application functions correctly across intended environments.
*   Identify and track defects effectively using JIRA.
*   Validate end-to-end user flows.


## 3. Testing Approach & Techniques

*   **Shift Left Testing:** Initiate testing activities early in the development lifecycle, starting with requirements analysis.
*   **Exploratory Testing:** Leverage team expertise to proactively identify potential issues beyond scripted test cases.
*   **End-to-End Flow Testing:** Simulate real user scenarios to validate integrated functionality.
*   **Smoke Testing & Sanity Testing:** Performed immediately after a stable build passes initial checks.
*   **Regression Testing & Retesting:** Repeat testing cycles to ensure changes haven’t introduced new issues.
*   **Usability, Functionality & UI Testing:** Comprehensive validation of the application's user experience and core features.
